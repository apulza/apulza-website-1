Apulza design system

Mobile · Account & Support

Five HTML/CSS re-creations of Apulza's Expo/React Native account, resources, and support screens, wrapped in a phone mockup for reuse in the marketing site's features section.

React Native → HTML/CSS Expo mobile app Phone mockup, 375×812 Tokens: mobile/src/constants/theme.ts
Note: these are faithful HTML/CSS re-creations built from the same ported design tokens as the live mobile app (mobile/src/constants/theme.ts, itself ported from DESIGN.md) — not literal React Native code, since React Native isn't a web technology and can't run in a browser. Colors, spacing, and radii below are copied 1:1 from Colors.light. The live app loads Figtree, JetBrains Mono, and Newsreader via expo-google-fonts; this page intentionally does not link Google Fonts (external font requests are silently blocked once published), so text below renders in the system-ui fallback instead.
