Apulza design system

Dashboard → marketing snippets

Five drop-in HTML/CSS pieces pulled straight from the live student dashboard — same tokens, same components, sample copy instead of real student data. Pure HTML and CSS, no React, no Tailwind, no icon library required.

5 snippets HTML + CSS only tokens match DESIGN.md
Font note — the live app loads Figtree via next/font/google. These snippets reference 'Figtree' first and fall back to your system font if it isn't loaded on your marketing page — load Figtree yourself for a pixel match, or leave the fallback if that's close enough.
