Breathing exercise → interactive snippet

The guided breathing tool from my-breathing, ported to vanilla JS. It's the same phase-timing math and easing as the live app — a small state machine driving CSS transform/opacity, not a canned animation loop — so it breathes at the real pace.

2 snippets fully interactive vanilla JS, no dependencies
This one needs JavaScript — unlike the static dashboard/cat-cafe pieces, the orb is driven by a small script (ported from the app's getPhaseInfo() logic). The copy button includes that script inline, so pasting the snippet anywhere just works — no build step, no imports. It respects prefers-reduced-motion automatically.
