Cat cafe → lounge snippet

The lounge scene, trimmed to 5 of its 8 cats, exactly as the real cat cafe renders it — same procedural SVG generator, same CSS keyframes, sample selection instead of a student's earned collection. Pure HTML/CSS/SVG, no React required.

2 snippets lounge scene only 5 of 8 lounge cats
How this was built — the cat/scene artwork is procedurally generated by components/student/cafe/cats.ts and scenes.ts, not static images. Rather than hand-copy that path data, the actual generator functions were run in Node to produce this exact markup — so every curve, gradient and animation timing below is pixel-identical to what students see in the app.
